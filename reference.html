Référence

Créer une note

-n | --note

Créer un nouveau fichier de type note en demandant le titre et le contenu.

❯ blaise --note
Enter note title: hello
Enter note content: world
Success: Created note.general.hello.md

Créer une tâche

-t | --task

Créer un nouveau fichier de type tâche avec des métadonnées de date d'échéance facultatives.

❯ blaise --task
Enter task title: hello
Enter due date (optional): 2026-09-15
Enter task content: world
Success: Created task.2026-09-15.general.hello.md

Modifier un fichier

-e | --edit

Modifier un fichier existant à l'aide de l'éditeur défini dans la configuration.

❯ blaise --edit
Select file to edit: note.general.hello.md
Opening note.general.hello.md in editor...

Déplacer un fichier

-m | --move

Déplacer ou renommer les fichiers sélectionnés en modifiant leurs champs.

❯ blaise --move
Select file to move: note.general.hello.md
Enter new path.filename: bye
Success: Moved note.general.hello.md to bye.md

Supprimer un fichier

-d | --delete

Supprimer un fichier existant avec un filtrage de chaîne de recherche facultatif.

❯ blaise --delete
Select file to delete: note.general.hello
Confirm deletion of note.general.hello.md (y/N): y
Success: Deleted note.general.hello.md

Ramifier un fichier

-b | --branch

Créer un nouveau fichier ramifié à partir d'un fichier source existant.

❯ blaise --branch
Select source file to branch from: note.general.hello.md
Enter new filename: bye
Success: Created branch from note.general.hello.md named bye.md

Lister les fichiers

-l | --list

Lister tous les fichiers actuellement stockés par Blaise.

❯ blaise --list
Listing all files:
note.general.hello.md
task.2026-09-15.send-project.md

Configurer le dépôt distant

-r | --remote

Connecter Blaise à un dépôt GitHub ou Codeberg distant.

❯ blaise --remote
Enter remote repository URL: git@github.com:Lohkinap/infogrames.git
Success: Connected to remote repository git@github.com:Lohkinap/infogrames.git

Afficher la version

-v | --version

Afficher la version actuelle de Blaise.

❯ blaise --version
blaise 0.1.0
