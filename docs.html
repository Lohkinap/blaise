Introduction

Blaise est un outil CLI de prise de notes en Markdown.

Chaque note est un fichier, stocké dans un répertoire unique sans sous-dossiers. Le nom du fichier porte l'information de hiérarchie ou de catégorie ; le système de fichiers reste plat. Les fichiers sont des fichiers texte simples, éditables avec n'importe quel éditeur et indexables par n'importe quel outil de recherche, sans dépendance à un logiciel propriétaire.

Installation

Les méthodes d'installation pour Linux, Windows et macOS seront bientôt disponibles.

Configuration

Définissez votre éditeur de texte et l'URL de votre dépôt distant dans le fichier de configuration.

Structure

Chaque fichier suit une convention de nommage stricte. La structure encode entièrement la catégorie et la hiérarchie.

Déplacez vos fichiers librement sans briser l'interprétation des données.

[type].[options].[path].[filename]

  • type : Définir le type de fichier (note ou task).
  • options : Ajouter des métadonnées optionnelles comme une échéance.
  • path : Préciser l'emplacement logique de la note.
  • filename : Indiquer le nom du fichier.

Stockage

Sauvegardez vos notes sous forme de fichiers texte simples dans un répertoire unique. Synchronisez l'ensemble de votre répertoire vers un dépôt distant distant avec la commande dédiée.

Modèles

Utilisez la commande de ramification pour créer un nouveau fichier à partir d'une note existante. Le nouveau fichier hérite du type et du chemin source. Conservez une traçabilité claire entre des notes reliées.

Obtenir de l'aide

Exécutez l'option d'aide dans votre terminal pour consulter le manuel.

Signaler des bugs

Ouvrez une issue sur le dépôt officiel en cas de comportement inattendu. Précisez la commande exécutée et le résultat obtenu.

Guide de contribution

Soumettez une pull request en respectant les conventions du projet.

Code de conduite

Respectez le code de conduite du projet lors de vos interactions et contributions.
